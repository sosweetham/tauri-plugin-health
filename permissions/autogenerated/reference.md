## Default Permission

Default permissions for the health plugin (auto-generated by build.rs based on enabled Cargo features).

#### This default permission set includes the following:

- `allow-is-available`
- `allow-request-permissions`
- `allow-check-permissions`
- `allow-open-settings`
- `allow-query-aggregated`
- `allow-query-sleep`
- `allow-query-workouts`
